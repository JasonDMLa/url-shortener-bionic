# URL Shortener

## Running the app

Run the backend and frontend in two separate terminals.

### Backend

```
cd backend
npm install
npm run start:dev
```

Runs on http://localhost:4000

### Frontend

```
cd frontend
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

## Running the tests

```
cd backend
npm test
npm run test:e2e
```

`npm test` runs the unit tests and `npm run test:e2e` runs the end-to-end tests.
